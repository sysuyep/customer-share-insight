# 阶段 0：访谈准备

访谈拿到的素材决定了分享能讲多深。后面 PPT 阶段反复出现的问题——讲不清为什么做某个决定、数字口径对不上、缺照片——很多是访谈时没问到。这一阶段的产出是背景笔记、访谈大纲、结束前确认清单和素材清单。

## 1. 背景调研

访谈前用约 60 分钟把资料过一遍。目的是设计追问，不是把资料写进 PPT。

| 维度 | 查什么 |
|---|---|
| 公司 | 官网（核心业务、案例）、LinkedIn 公司页（定位、规模、招聘动态）、近一年的新闻或采访 |
| 个人 | 本人的 LinkedIn、过往演讲视频、文章、公开发言 |
| 行业 | 这个行业的关键难题、外部冲击（如疫情、价格战、技术变化）、常见成长路径 |
| 内部资料 | 学员档案、所在班级、上过哪些课、班主任或教练的观察、以往的洞察报告（用户提供时使用） |

写背景笔记时：

- 每条事实注明来源链接；查不到写"未找到"，不要推测。
- 公开资料多的人，访谈要追问没公开过的细节；几乎没有公开资料的人，访谈本身就是挖一手故事的机会，问题要更开放、更细。
- 最后列出 3–5 个值得追问的点，作为设计追问的依据。

## 2. 一次访谈要拿到的三样东西

| 目的 | 要拿到什么 | 怎么问 |
|---|---|---|
| 素材 | 第一手故事、具体细节、原话 | 问具体场景，让对方讲细节，不让对方做总结 |
| 痛点 | 对方现在真正卡在哪里 | 在追问故事的过程中自然暴露，不直接问"你的痛点是什么" |
| 学习价值 | 课程带来的启发，由对方自己说出来 | 只给一个开放入口，对方不接就不追 |

一个好问题可以同时拿到几样。例如"这些年你最大的认知变化是什么？"能同时带出故事、卡点和学习收获。

## 3. 设计大纲的六条原则

1. **问小问题，问具体场景。** 不问"你有没有总结出一套方法论"，对方平时也没系统总结过，只会卡壳或讲大词。改问"一个新客户第一次来找你，你们通常聊什么？""从接单到交付经过几个步骤，哪一步最花时间？"方法会从对方描述的做法里自然出现。
2. **按顺序递进。** 分享人是谁、公司做什么 → 公司怎么经营、战略怎么选 → 外部压力 → 内部挑战（团队、管理）→ 学习与系统化 → 愿景与分享意愿。没问完战略就跳到团队管理，对方答不清楚。
3. **不超过 18 个问题。** 每个问题要么能拿到故事，要么能暴露痛点，要么能引出学习价值，三样都不沾的删掉。意思重复的合并，比如"早期怎么活下来"和"被压价最难堪的时刻"其实是同一层问题。
4. **追问提前设计。** 每个主问题下预设 1–3 个追问，基于背景笔记来写，也要有情绪类的追问，比如"那时候最难开口的一句话是什么？"。
5. **访谈和 PPT 分开。** 大纲里不写"这个问题对应 PPT 第几页"。访谈要尽量多收集素材，提前绑定页面会漏掉好故事。
6. **课程只给一个入口。** 例如"有没有哪些工具或思考方式，是你学到以后觉得'早知道就好了'的？"对方主动讲就深挖，不讲就放下，不硬引。

## 4. 五个必问点

这几项在后续制作中最常缺，访谈时就要问到：

| 必问点 | 为什么 |
|---|---|
| 每个关键决定的处境、判断、动作、结果 | 只有动作没有判断，分享讲不出眼光。例如"别人都在收缩，你为什么还扩张"，要问到当时是怎么想的 |
| 数字的单位、币种、年份、统计范围 | 转写稿里的数字常有歧义，如营收是哪种货币、员工数是否含外包 |
| 哪些内容可以公开 | 避免做完再删。敏感数字、合伙纠纷、家庭细节当场确认 |
| 最骄傲的事、最难忘的瞬间 | 最打动人的细节只能靠追问得到，比如为了一个产品细节专门投入、某位顾客的一句话 |
| 照片素材 | 缺照片只能用示意图补，真实感会下降 |

## 5. 大纲模板

```markdown
# [姓名] 访谈大纲（[日期]，约 [60–90] 分钟）

本次目的：素材 / 痛点 / 学习价值
已知背景：[3–5 条关键事实，注明来源]

## 一、您和公司（2–3 题）
1. 公司现在主要做什么？客户是谁？
   - 追问：哪一类客户贡献最大？为什么是他们？

## 二、公司怎么经营、战略怎么选（3–4 题）
2. 回头看，有哪一个决定改变了公司的走向？当时是什么情况？
   - 追问：当时有人反对吗？您为什么还是这么决定？

## 三、外部压力（2–3 题）

## 四、内部挑战：团队与管理（3–4 题）

## 五、学习与系统化（2 题，含一个课程开放入口）

## 六、愿景与分享意愿（2 题）
- 最骄傲的一件事是什么？
- 如果台下坐着和您三年前一样的老板，您最想对他们说什么？

## 访谈结束前确认
- [ ] 关键数字的单位、年份、范围
- [ ] 哪些内容不公开
- [ ] 照片素材清单和提供时间
- [ ] 分享场合、时长、语言、需要的文件格式
```

## 6. 素材清单

访谈结束时请对方提供，或约定提供时间：

- 公司 Logo（矢量或高清 PNG）
- 本人正式照片 1–2 张
- 公司门头、工厂、门店或办公室全景
- 业务现场：生产、施工、服务、产品照片
- 团队合影、年会、培训等活动照片
- 公司愿景、使命、价值观的正式文字
- 需要上屏的数字的正式版本（营收、人数、门店或站点数等）

## 7. 访谈后处理转写稿

- 先自己通读一遍，标出转写错误的地名、人名、公司名、数字。
- 统一命名存放，例如 `[编号] [姓名]_原始录音文本.md`，照片素材和转写稿放在同一个文件夹。
- 拿到转写稿后，进入阶段 1。
