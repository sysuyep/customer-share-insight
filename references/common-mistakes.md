# 执行中的常见错误

本 Skill 在不同模型和不同渠道（Claude、Codex、企业微信里的智能助手）上都跑过，下面这些错误反复出现。执行中发现自己正在犯其中一条，就按"怎么做"纠正。

| 错误 | 为什么会出问题 | 怎么做 |
|---|---|---|
| 阶段结束后自己接着做下一阶段 | 用户还没确认主线，后面的工作可能全部白做 | 每个阶段以一个确认问题结束，然后停下等回复 |
| 在同一条回复里自问自答"好的，那我开始阶段 2" | 用户失去了修改方向的机会 | 问完就结束本条回复 |
| 用户说"继续"就开始做页面 | 阶段 3 分条发送时，"继续"通常指发下一个模块 | 先看阶段 3 是否全部发完、是否问过"是否开始做页面"；不确定就问 |
| 跳过逐页框架，直接用模块级的讲述逻辑做页面 | 讲述句被放上页面、页间跳跃、数字重复，成品出来后要返工几个小时 | 阶段 3 必须写到每一页，并输出标题连读和自查结果 |
| 阶段 4 还在对话里一段段发 Markdown 或 HTML | 文件没有落盘，用户拿不到可用的东西 | 阶段 4 直接把三个文件写到磁盘，对话里只给路径和检查结果 |
| 用文字描述"HTML 报告大概长这样"代替真实文件 | 用户无法打开使用 | 必须写出真实的 `.html` 文件；当前环境不能写文件时直接说明 |
| HTML 文件里残留 `html += """`、`# SECTION 1` | 心里想用脚本拼接，实际却把脚本代码写进了文件 | 直接写 HTML；要用脚本就真正运行脚本，把输出写进文件 |
| 在企业微信里一次发完整个框架 | 消息被截断，代码块断在中间 | 按 `page-plan.md` 第 4 节每个模块一条消息 |
| 从零写演示稿样式 | 漏掉缩放脚本、打印设置、深色模式，字号和配色也容易出问题 | 复制 `assets/deck-template.html` 再改 |
| 为了塞下文字把字号改小 | 会场后排看不清 | 字多就拆页 |
| 反复全量截图、反复重试生成图片 | 一轮修改拖到两个小时 | 只检查改过的页；图片连续失败两次就放占位 |
| 交付时只说"已完成" | 用户找不到文件 | 给出每个文件的完整路径 |
| 引用了旧版本的 Skill 文件夹 | 旧版本缺少后来补上的规则 | 使用前看 SKILL.md 开头的版本号和更新日期 |
